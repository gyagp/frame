## 用户明确划定的技术边界

- 主体是可重复制作不同作品的 studio / 电影引擎，首部电影只是一个项目。
- 先 2D；Blender 等本地开源引擎允许，3D 暂不实施。
- 允许直接使用 Nano Banana 和 Azure Speech。
- 不使用 Pika、Seedance 等收费视频生成工具或依赖其平台完成影片。
- 用户只做必要选择，其余由大模型承担；但故事、画面和短样片必须可审阅后再推进。

## 从参考到当前实现

1. `project.brief`：主题、观众、故事、风格、节奏、参考、素材、声线与画幅。
2. `project.bible`：一句话故事、弧线、视觉规则和连续性。
3. `scene.direction`：镜头目的、取景、调度、动作和转场意图。
4. `scene.composition`：模型生成、受约束的 2D 场景图；它是引擎的数据，不是外部工具的 prompt。
5. `scene.soundCues`：与画面同一时间基准的音效。
6. 内容绑定的审阅：分镜 → 关键画面 → 带声样片 → 全片。
7. 用实际渲染静帧作多模态审片，明确该检查不包含运镜与听感。

所有代码均为本项目编写；没有克隆上述视频平台或把它们包一层 UI 当作引擎。
方法讨论保留作者署名；未复制它们的整套素材、付费配方库、角色和影片。
