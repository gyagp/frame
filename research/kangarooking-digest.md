## 可迁移的方法

| 方法 | 本 Studio 的做法 | 本片示例 |
|---|---|---|
| 尺度需要参照 | 固定角色尺寸、地平线、水位和机位；不靠夸张变形制造大小 | 老牛／松鼠／小马面对同一条河，河没有为不同镜头改变深度 |
| 前中后景承担不同任务 | 前景提供视差，中景承载动作，远景交代目的地；按镜头选择景深 | 前景芦苇、中景小马、远景磨坊；眼神特写可以浅景深，交代渡河路线时需要看清两岸 |
| 摄影机只有一个主导路径 | 写位置、朝向、目标、速度变化和终点；区分真实位移与焦距变化 | 试水镜头随蹄子缓降后停住；过河镜头侧向平行跟拍，避免任意环绕越轴 |
| 情绪通过动作和后果表达 | 写準备、接触、力／重心方向、环境反应与结果 | 犹豫是蹄子悬停、耳朵垂下、重心后退；勇敢是观察后慢慢承重 |
| 时间按事件阶段分配 | 不为每一秒硬塞事件；对白、动作与停留各有空间 | 14 秒试水：观察 → 探蹄 → 承重 → 站稳，实际声音测时后微调 |
| 尾帧是下一镜输入 | 记录角色位置、朝向、脚步相位、道具状态、相机和水纹 | 上岸后蹄子已离水，下一镜不得重新变成河中悬步 |
| 参考素材职责明确 | 身份、美术、结构、动作、运镜分别标记“保留”和“可变” | 改材质不改浅滩入口；学相机路线不复制参考片角色 |
| 迭代只改一个主要变量 | 单镜保存反馈、修改范围、旧版、结果与未解决问题 | 先修蹄滑，再调水花，再调光；旁白无变化则复用语音 |
| 声音有距离和接触点 | 近处蹄水声、中景流水、远处风鸟声；接触声与动作同时间点 | 先让音乐让开落水声，再恢复主题；不用持续巨大音效掩盖动作 |

“每段一个主运镜”是避免矛盾和提高可读性的默认做法，不是禁止经过预演的复合运动。
不能把玄幻场面的一直追尾、冲击慢动作、爆炸和强对比配色套到温柔的亲子故事上。

## 本地 3D 与生成视频的区别

原文靠模型理解提示词，在失败时重新生成；本地 3D 则必须真正创建网格、绑定、动画曲线、
相机和环境响应。提示词中的“蹄子不能滑”“水纹连续”只是需求，必须实现和审查。
图片能提供美术方向，不能凭空带来可变形的四足骨骼或可重拍的场景。

Studio 的导演输出应含：镜头目的、空间参照、动作阶段、相机约束、环境反馈、
声音事件、结束状态、参考职责和验收重点。现有 `scene.direction` 可保存可读计划；
未来 Blender 编译器再把经过验证的字段变成可信执行参数，禁止任意脚本字符串。

本次改进为技能与项目设计，不声称已经完成 Blender 编译器或影片。
