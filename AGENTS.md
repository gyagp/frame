# Movie Studio

This repository is a local filmmaking workspace. Keep the user's requested audience,
language, duration and source material in `projects/<id>/project.json`.

The user explicitly requires story/shot approval, keyframe approval, then a voiced
short sample before completing the rest. Preserve those gates; never forge approval
fields to make a render pass. Use Azure Speech for narration. Do not add Google
narration choices. The first subgroup-matrix film is English, 150 seconds, 16:9.

## Skills

Read the relevant repository skill under `.agents/skills/`:

- `film-research`: ingest references and maintain claim provenance.
- `film-director`: brief, treatment, style, storyboard and timed narrative.
- `film-motion`: deterministic graphics and footage composition.
- `film-sound`: narration, subtitles, cue-driven score and mixing.
- `film-finishing`: render, review and delivery with explicit check results.
- `technical-demo-film`: technical explanations and benchmark comparisons.
- `film-shot-language`: framing, staging, motion and transition grammar.
- `film-continuity`: identity, spatial and visual continuity across shots.
- `film-quality-review`: actual-frame critique and targeted revision.
- `film-3d`: editable assets, blocking, rigged performance and local 3D production.
- `anatomy`: detailed isometric SVG mechanisms and interactive technical explainers;
  read its Movie Studio notes before using an illustration in a film.

Prioritize the reusable studio and engine over any individual film. Ordinary films
use the data-only 2D composition engine in `src/engine/`. Do not evaluate arbitrary
LLM-written JavaScript. Nano Banana and Azure Speech are authorized providers;
Blender and other local engines are permitted for explicitly requested 3D work.
Pika, Seedance and similar paid video generation tools are excluded. The existing
production renderer is 2D; 3D projects must not silently fall back to it. The user
has requested a 3D Little Pony Crosses the River film under five minutes; verify
each new backend before describing it as integrated or production-ready.

Keep the guided workspace simple without lowering rendering or production quality.
Preserve the complete editor behind "精细调整". Each stage should have one clear
primary action; completed exports should be played/downloaded, not regenerated by
accident. Connection settings belong to each user's home directory, never to a
shared project. Gemini and GitHub Copilot are supported director backends; image
and speech credentials are configurable. Testing draft settings must not overwrite
a working connection. Never return stored secrets to the browser.

Do not silently promote old benchmark snapshots into current measurements. Demo
replay is not live GPU execution. Retain baseline, precision, hardware and date.

`src/film.mjs` is shared by the browser preview and frame renderer. It must be a
pure function of project, time and loaded assets. Keep wall-clock state out of it.
`src/model.mjs` validates saved and rendered projects. No browser-supplied shell
commands or arbitrary filesystem paths. Local service binds to loopback only.

Run `npm test` after changing timeline, validation, API or rendering behavior.
Use `npm run test:ui` for UI interactions and inspect saved screenshots. Render
three representative frames before a full render. Keep generated videos out of
Git, preserve source snapshots and credits. Never claim ASR or listening checks
passed unless actually performed.
