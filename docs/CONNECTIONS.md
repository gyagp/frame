# 每个人连接自己的创作工具

打开侧栏「连接设置」。检查连接可以验证尚未保存的配置，不会覆盖正在使用的配置。
满意后点击「保存连接设置」；接下来的任务生效，无需重启。
作品正在生成时，先等任务结束再保存连接更改，避免同一部影片中途换服务。

## 导演与动画编排

- **Gemini**：选择模型，填写 Google API Key。与 Nano Banana 共用密钥。
- **GitHub Copilot**：使用本机 Copilot / GitHub CLI 的登录，或填写拥有 Copilot 权限的
  GitHub Token。模型默认 `auto`，也可从「检查导演连接」返回的模型列表选择。

Copilot 使用官方 `@github/copilot-sdk` 1.0.16 和随 SDK 提供的运行时。工作室仅请求
文本 / 图片推理，关闭文件、命令、MCP 和自定义工具执行，模型仍输出同一份可校验的
电影方案与 2D 场景数据。它不会接管用户的代码仓库。

官方依据：<https://github.com/github/copilot-sdk/tree/main/nodejs>。
实际验证过当前登录的模型列表、JSON 文本请求及图片识别请求。

## 图片

- **Nano Banana / Google**：API Key、图片模型都可在界面修改。
- **已有素材与代码画面**：使用上传的图片或引擎绘图，不调用生图服务。

不提供 Pika、Seedance 等收费视频生成平台。

## 配音

- **Azure Speech**：填写自己的 Speech Key 和服务区域，例如 `japaneast` / `eastus`。
  中文、英文默认声线分别可选。
- **Azure CLI**：Windows 用户已运行 `az login` 时，可在进阶项填写订阅、资源组和
  资源名，由服务在进程内读取密钥。其他系统建议直接填写 Speech Key。
- **Windows 本地语音**：离线方案，只适用于 Windows 已安装的声音。

默认声线用于新作品。已有作品保留自己的声线选择，需要更换时在「精细调整」中修改。
Google 配音不在可选项中。

## 配置与分享

个人配置默认写入 `~/.movie-studio/connections.json`，位于仓库外。该文件含个人密钥，
留在本人账户下，不加入分享包。网页只返回「是否已配置」，不回显已保存的密钥。
密码框留空保留原值，明确勾选清除才移除保存的密钥。

已有 `.env` 或环境变量仍作为默认值兼容。保存的个人设置优先。
可用 `MOVIE_STUDIO_SETTINGS_FILE` 为隔离安装或自动化测试指定其他配置文件。

分享时提供源码和依赖清单即可，接收者运行 `npm install`、`npm start` 后配置自己的服务。
Node.js 推荐 22 LTS（最低兼容范围为 ^20.19.0 或 >=22.12.0），还需要 FFmpeg / FFprobe。
各模型的可用性、配额与费用由使用者自己的服务账号决定。

## Copilot 模型选择

在「连接设置 → 导演与动画编排」选择 GitHub Copilot，工作室会读取当前账号可用的模型，
显示为下拉列表。选择模型后保存即可；也可以点击「刷新可用模型」重新读取。
例如账号提供 GPT-6 Astra 时，对应模型 ID 为 `gpt-6-astra`。
连接检查会核对所选模型是否在账号列表中，未找到时保留原设置并提示重新选择，
不会自动换成别的模型。刷新列表和检查草稿连接不会保存设置。
